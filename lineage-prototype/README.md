# 리니지풍 미니 프로토타입 (0단계: 이동)

리니지 감성(탑다운 핵앤슬래시)의 핵심 루프 "이동 → 사냥 → 성장"을 단계별로
검증하기 위한 프로토타입입니다. 저장소 루트의 Armstrong(우주 탐험) 프로젝트와는
완전히 별개의 Godot 프로젝트이며, 서로의 코드를 참조하지 않습니다.

## 실행 방법

1. [Godot 4.x](https://godotengine.org/download) (4.3 이상 권장) 설치
2. Godot 프로젝트 매니저 → "가져오기(Import)" → 이 폴더의 `project.godot` 선택
   - 저장소 루트에도 `project.godot`(Armstrong)이 있으므로, 반드시
     `lineage-prototype/project.godot`을 직접 골라야 합니다.
3. F5로 실행

## 조작

| 입력 | 동작 |
|---|---|
| W A S D | 8방향 이동 |

지금은 이동만 됩니다. 이미지/스프라이트 없이 원판을 코드로 그려서(`_draw()`)
표시하며, 격자 바닥도 같은 방식으로 그립니다. Armstrong과 동일하게 "텍스처
파일 없이 코드/셰이더로 그리기" 스타일을 따릅니다.
