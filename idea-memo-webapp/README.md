# 아이디어 메모장 (3단계: 검색/태그)

코딩을 몰라도 실행해볼 수 있도록, 터미널(명령어를 입력하는 검은 화면)에 그대로
복사해서 붙여넣을 수 있는 명령어를 적어뒀어요.

## 왜 "그냥 파일 더블클릭"으로 열면 안 되나요?

이 앱은 "서비스 워커(Service Worker)"라는 오프라인 지원 기능을 쓰는데,
이 기능은 보안상의 이유로 `http://` 또는 `https://` 주소로 열었을 때만 작동해요.
파일을 더블클릭해서 여는 `file://` 방식으로는 작동하지 않습니다.
그래서 아주 가벼운 "로컬 서버(내 컴퓨터 안에서만 돌아가는 미니 웹서버)"를 하나 띄워야 해요.

## 실행 방법

터미널을 열고, 이 프로젝트 폴더로 이동한 뒤 아래 명령어를 입력하세요.

```bash
cd idea-memo-webapp
python3 -m http.server 8080
```

- `cd idea-memo-webapp` : "이 폴더로 들어간다"는 뜻이에요 (cd = change directory, 폴더 이동).
- `python3 -m http.server 8080` : 파이썬에 내장된 아주 작은 웹서버를 8080번 포트로 켠다는 뜻이에요.
  (요즘 컴퓨터에는 대부분 파이썬이 이미 설치되어 있어서 별도 설치 없이 바로 됩니다.)

명령어를 입력하면 터미널이 멈춘 것처럼 계속 떠 있는데, 정상이에요. 서버가 계속 켜져 있는 중입니다.

이제 브라우저(크롬 등)를 열고 주소창에 아래 주소를 입력하세요.

```
http://localhost:8080
```

- 오른쪽 아래 **+ 버튼**을 눌러 제목/내용을 쓰고 "저장"을 누르면 카드가 생기면 성공입니다.

서버를 끄고 싶을 땐 터미널에서 `Ctrl + C` 를 누르면 됩니다.

## 지금까지 만든 것 (3단계: 검색/태그)

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조. 검색창, 태그 필터 칩, 정렬 드롭다운, 작성/수정 팝업이 있어요. |
| `css/style.css` | 카드 목록, 팝업창, 검색창, 태그 칩 등 디자인. |
| `js/storage.js` | **저장 담당.** 메모 저장/조회/수정/삭제 + 태그 목록 뽑아오기(`getAllTags`). |
| `js/app.js` | **화면 담당.** 버튼 클릭, 카드 그리기, 검색·태그 필터링, 정렬을 처리해요. |
| `manifest.json` | PWA 설정 파일. |
| `service-worker.js` | 오프라인 캐싱 스크립트. 캐시 버전 v2 → v3으로 올렸어요. |
| `icons/` | 앱 아이콘. |

**`storage.js`와 `app.js`를 나눠 놓은 이유:** 지금은 "저장 담당" 파일이 브라우저 저장소(localStorage)를
사용하지만, 나중에 클라우드 동기화를 붙일 때는 이 파일 안의 함수들만 서버 통신 코드로 바꾸면 돼요.
화면을 그리는 `app.js`는 건드릴 필요가 없습니다.

### 이번 단계에서 된 기능
- ✅ 메모 작성 (제목 + 자유 텍스트 내용 + 태그)
- ✅ 카드 목록으로 표시, 클릭(카드 제목 부분)하면 내용 펼치기/접기
- ✅ 수정(✏️) / 삭제(🗑️) 버튼
- ✅ 정렬: 최신순 / 오래된순 / 제목순
- ✅ 퀵캡처: 화면 오른쪽 아래 + 버튼이 어디서나 항상 떠 있어서 바로 새 메모 작성 가능
- ✅ **검색**: 검색창에 타이핑하는 즉시(엔터 없이) 제목·내용에서 찾아서 보여줘요.
- ✅ **태그**: 메모 작성/수정 시 `아이디어, 할일`처럼 쉼표로 구분해 태그를 붙이고,
  화면 위쪽 태그 칩(또는 카드 안 태그)을 눌러 그 태그가 붙은 메모만 걸러볼 수 있어요.
  검색과 태그 필터는 동시에(AND 조건으로) 적용돼요.
- ⬜ 다크모드는 4단계(디자인)에서 추가 예정

기존에 2단계에서 만들어둔 메모(태그 없이 저장된 것)를 계속 쓰셔도 괜찮아요.
`storage.js`가 불러올 때 자동으로 빈 태그 목록을 채워 넣도록 만들어뒀거든요.

## 배포 (GitHub Pages)

이 폴더가 바뀌어서 `claude/idea-memo-webapp-mivnhu` 브랜치에 푸시될 때마다,
`.github/workflows/deploy-idea-memo-pages.yml` 워크플로우가 자동으로 이 폴더를
GitHub Pages(깃허브가 무료로 제공하는 정적 웹사이트 호스팅)에 올려줘요.

**단, 이 저장소에서 GitHub Pages를 처음 쓰는 거라 사람이 딱 한 번 해줘야 하는 설정이 있어요**
(보안을 위해 깃허브가 저장소 소유자의 직접 클릭을 요구하는 부분이라, 자동화로 우회할 수 없어요):

1. https://github.com/zergrrrr77-hue/Armstrong 접속
2. 상단 탭에서 **Settings** 클릭
3. 왼쪽 메뉴에서 **Pages** 클릭
4. **Build and deployment → Source** 드롭다운에서 **"GitHub Actions"** 선택

이 설정을 한 번만 해두면, 그 다음부터는 이 브랜치에 뭔가 바뀌어서 푸시될 때마다
자동으로 재배포됩니다. 배포되면 주소는 다음과 같아요.

```
https://zergrrrr77-hue.github.io/Armstrong/
```

배포 진행 상황은 저장소의 **Actions** 탭에서 확인할 수 있어요.
