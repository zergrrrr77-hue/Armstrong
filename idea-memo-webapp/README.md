# 아이디어 메모장 (1단계: 기본 틀)

코딩을 몰라도 실행해볼 수 있도록, 터미널(명령어를 입력하는 검은 화면)에 그대로
복사해서 붙여넣을 수 있는 명령어를 적어뒀어요.

## 왜 "그냥 파일 더블클릭"으로 열면 안 되나요?

이 앱은 "서비스 워커(Service Worker)"라는 오프라인 지원 기능을 쓰는데,
이 기능은 보안상의 이유로 `http://` 또는 `https://` 주소로 열었을 때만 작동해요.
파일을 더블클릭해서 여는 `file://` 방식으로는 작동하지 않습니다.
그래서 아주 가벼운 "로컬 서버(내 컴퓨터 안에서만 돌아가는 미니 웹서버)"를 하나 띄워야 해요.

## 실행 방법

터미널을 열고, 이 프로젝트 폴더로 이동한 뒤 아래 명령어를 입력하세요.

```bash
cd idea-memo-webapp
python3 -m http.server 8080
```

- `cd idea-memo-webapp` : "이 폴더로 들어간다"는 뜻이에요 (cd = change directory, 폴더 이동).
- `python3 -m http.server 8080` : 파이썬에 내장된 아주 작은 웹서버를 8080번 포트로 켠다는 뜻이에요.
  (요즘 컴퓨터에는 대부분 파이썬이 이미 설치되어 있어서 별도 설치 없이 바로 됩니다.)

명령어를 입력하면 터미널이 멈춘 것처럼 계속 떠 있는데, 정상이에요. 서버가 계속 켜져 있는 중입니다.

이제 브라우저(크롬 등)를 열고 주소창에 아래 주소를 입력하세요.

```
http://localhost:8080
```

- "기본 틀만 만들어진 상태예요" 라는 문구와 오른쪽 아래에 동그란 + 버튼이 보이면 성공입니다.

서버를 끄고 싶을 땐 터미널에서 `Ctrl + C` 를 누르면 됩니다.

## 지금까지 만든 것 (1단계: 기본 틀)

| 파일 | 역할 |
|---|---|
| `index.html` | 화면에 보이는 뼈대(구조). 지금은 제목과 안내 문구, 빈 + 버튼만 있어요. |
| `css/style.css` | 색, 여백, 버튼 모양 등 디자인 담당. |
| `js/app.js` | 화면의 동작(로직) 담당. 지금은 "서비스 워커 등록"만 해요. |
| `manifest.json` | "이 웹사이트는 앱처럼 설치할 수 있다"고 브라우저에 알려주는 설정 파일 (PWA의 핵심). |
| `service-worker.js` | 파일들을 미리 저장해서, 인터넷 없이도 앱이 열리게 해주는 스크립트. |
| `icons/` | 앱 아이콘 이미지들 (홈 화면에 추가했을 때 보이는 아이콘). |

아직 메모를 쓰거나 저장하는 기능은 없어요. 다음 단계에서 추가할 거예요.

## 다음에 할 일 (2단계 예고)

2단계에서는:
1. 화면 오른쪽 아래 **+ 버튼을 눌러서 메모(제목 + 내용)를 쓰는 창**을 만들고,
2. 쓴 메모를 **브라우저 로컬 저장소(localStorage)**에 저장하고,
3. 저장된 메모들을 **카드 목록**으로 화면에 보여주고,
4. 카드를 클릭하면 내용이 펼쳐지게 만들고,
5. 메모를 **수정/삭제**할 수 있게 만들 거예요.

지금 1단계 화면이 잘 뜨는지 확인해보시고, 잘 되면 "다음 단계 진행해줘" 라고 알려주세요!
