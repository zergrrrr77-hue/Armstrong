# 외부 그림 출처 (사용자 제공)

| 파일 | 게임에서 쓰는 곳 | 출처·사용 조건 |
|---|---|---|
| trees_plants_rocks.png | ext_boulders, ext_cairns, ext_dolmen, ext_log, ext_log_rune, ext_grave, ext_grave_broken, ext_stump, ext_trough, ext_flatstones, ext_tree_a, ext_tree_b, ext_bush_aut | 사용자 제공, 원작자·조건 확인 필요 |
| trees_plants.png | ext_deadtree_big, ext_deadtree_s, ext_scarecrow, ext_pumpkins | 사용자 제공, 원작자·조건 확인 필요 |
| town.png | ext_well, ext_fountain, ext_statue, ext_pedestal | 사용자 제공, 원작자·조건 확인 필요 |

- 잘라 쓰는 위치와 색 보정은 `tools/lineage/ext_props.py` 에 있다.
- 게임을 공개하거나 판매하기 전에 각 파일의 원본 페이지에서 사용 조건(CC-BY, CC-BY-SA, GPL 등)을 확인하고,
  요구하는 경우 게임 안 '만든 사람들' 화면에 제작자 이름을 표시한다.
- 함께 올라온 rocks.zip(LPC, CC-BY-SA 3.0 / GPL 3.0)은 아직 게임에 쓰지 않았다.
