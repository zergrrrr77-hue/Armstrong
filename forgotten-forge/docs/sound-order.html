게임에 들어갈 소리 59개의 목록입니다. 줄마다 프롬프트를 복사해 생성하고, 표에 적힌 파일 이름으로 저장해 대화창에 올려 주세요. 노란 먼저 표시 25개만 있어도 게임 분위기가 크게 바뀝니다.

효과음 · ElevenLabs
  1. elevenlabs.io에서 Sound Effects 메뉴를 엽니다.
  2. 프롬프트를 붙여 넣고, Duration을 표의 길이로 직접 맞춥니다.
  3. Prompt influence는 높게(약 70%) 둡니다.
  4. 여러 결과 중 가장 좋은 것을 받아 파일 이름을 바꿉니다.

무료 플랜은 크레딧이 적으니 먼저 표시부터 만드세요. 마음에 드는 후보가 둘이면 hit_sword_2.mp3처럼 번호를 붙여 함께 주시면 게임에서 번갈아 재생합니다.

배경음악 · Suno
  1. Create에서 Custom 모드를 켭니다.
  2. Instrumental(연주곡)을 켭니다.
  3. 프롬프트를 Style of Music 칸에 붙여 넣습니다.
  4. 두 결과 중 하나를 골라 Download → MP3로 받습니다.

필드 곡은 보내 주실 Suno 곡을 쓰면 만들지 않아도 됩니다. 반복 이음새와 음량은 제가 맞춥니다.
