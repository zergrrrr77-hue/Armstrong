# 잊혀진 대장간 — 보관용 마스터 문서 (v0.7 · 2026-11)

이 문서 하나로 지금까지 만든 게임을 **다시 꺼내 쓸 수 있게** 압축했습니다.

- **A. 보관 위치:** 코드를 통째로 되살리는 방법
- **B. 다시 만들기 프롬프트:** 새 프로젝트에서 AI에게 그대로 붙여 넣는 한 장짜리 사양
- **C. 시스템 명세:** 수치 전부
- **D. 그림·소리 제작법:** 그래픽과 소리를 만드는 방법
- **E. 겪은 버그와 교훈:** 새로 만들 때 같은 실수를 피하기 위한 기록
- **F. 재사용할 만한 코드 조각:** 다른 게임에 옮겨 쓸 수 있는 부분

## B. 다시 만들기 프롬프트 (복사해서 새 프로젝트에 붙여 넣기)

```
너는 웹 게임 개발자다. 브라우저 하나로 도는 "리니지풍 쿼터뷰(2:1 아이소메트릭) 액션 RPG"를 만든다.
제목: 잊혀진 대장간. 언어: 한국어. PC(키보드·마우스)와 휴대폰(가로·세로, 터치)을 처음부터 함께 지원한다.

[기술]
- HTML5 캔버스, 프레임워크 없이 단일 HTML(+그림 폴더). 캔버스는 '게임 픽셀' 해상도로 그리고 CSS pixelated로 확대(줌 1.5~2.5).
- 그림: 미리 렌더링한 도트 스프라이트 시트(8방향 × 동작별 프레임) + meta.json(프레임 크기·기준점·동작 범위).
- 소리: Web Audio 합성 효과음 + 장면별 배경음악(마을·필드·던전·보스전), 분류별 볼륨(전체·배경·효과·몬스터·환경).
- 저장: localStorage 자동 저장(5초) + 이어하기. 버전이 바뀌어도 예전 저장을 읽을 수 있게.
- 자동 테스트(Playwright)로 기능마다 확인. "시험용 손잡이" window.__game 을 둔다.

[게임 구조]
- 클래스 3종: 기사(근접·튼튼), 요정(원거리 활·빠름), 마법사(원거리 마법). 스킬 4개(Lv 1·2·4·6 해금).
- 맵 2개: 마을 외곽(60×60, 마을=안전지대, 숲·늪·묘지·야영지) / 지하 묘소 던전(34×34, 어둡고 횃불 조명, Lv 5부터).
- 몬스터 7종 + 보스(몰락한 왕) + 맵마다 월드보스(하루 4번 0·6·12·18시).
- 장비 11칸(리니지식), 등급 6단(일반·고급·희귀·영웅·전설·유니크), 강화 +10(안전 구간 넘으면 실패 시 +0).
- 같은 장비도 능력치를 범위 안에서 따로 굴리고 '상위 %'로 표시, 매우 희귀한 특수 패시브.
- 상점 NPC(화로의 신), 웨이포인트 순간이동, 귀환·이동 스크롤, 몬스터 전리품, 골드 뽑기(펫·변신 인형), 개발자 모드.

[반드시 지킬 것 — 이전 버전에서 실제로 겪은 문제]
1. 화면 위 버튼은 실제로 눌리는지 테스트한다(HUD 컨테이너의 pointer-events:none이 버튼 자신에게 걸리면 클릭이 캔버스로 빠짐).
2. 글자만 보여 주는 HUD(로그·배너)는 pointer-events:none — 조이스틱 터치를 가로채지 않게.
3. 휴대폰: viewport 메타 필수. 터치 금지(touch-action:none)는 캔버스·조이스틱에만. 창은 스크롤 대신 탭/페이지로 나눠 한 화면에 들어가게.
4. 맵 생성 후 '도달 가능 영역'을 계산하고, 출현 자리·저장 위치·순간이동 지점을 가장 가까운 빈 칸으로 보정. 막힌 칸에 들어가면 즉시 탈출.
5. 몬스터 목소리는 몬스터별 쿨타임 + 전체 초당 3회 제한. 상태(추격↔대기)가 매 프레임 바뀌지 않게 대기 시간을 둔다.
6. 밸런스는 시뮬레이션(화면 없이 게임 시간 빠르게)으로 측정해서 정한다. 감으로 배율을 올리지 않는다.

[만드는 순서]
1단계 이동·카메라·충돌·길찾기(A*) → 2단계 기본 공격·피격 손맛 → 3단계 스킬·이펙트 → 4단계 몬스터 AI
→ 5단계 드롭·가방·장비 → 6단계 강화·상점 → 7단계 휴대폰 UI(조이스틱·공격 버튼·탭 창) → 8단계 던전·보스
→ 9단계 월드보스·뽑기·웨이포인트 → 단계마다 테스트와 밸런스 시뮬레이션.
수치는 아래 'C. 시스템 명세'를 출발점으로 쓴다.
```

### C-3. 장비·강화·드롭
- 장비 칸 11: 투구·목걸이·무기·갑옷·방패(기사)·망토·장갑·장화·반지 2·팔찌. 착용 Lv: 일반 1·고급 3·희귀 6·영웅 9·전설 12·유니크 10
- **개별 수치:** 능력치마다 기본값 × 0.80~1.25를 따로 굴린다. 상위 % = (1 − r) × 100, 장비 전체는 평균의 정확한 분포(Irwin–Hall)로 계산
- **강화:** 무기는 +6까지, 갑옷은 +4까지 100%. 그 뒤 무기 50/40/30/20%, 갑옷 60/50/40/30/25/20%. 실패하면 +0. 강화 1단계당 공격 +2.4, 방어 +1.5
- **특수 패시브(7종):** 메아리(직업 스킬 무작위 1회 추가 발동 10~20%)·연속 타격·흡혈·마나 순환·처형·불굴·시간 왜곡
  - 확률: 0.4% × 등급 배율(1·1.5·2.5·4·6), 보스 ×5, 월드보스 ×10
- **보스 드롭:** 장비 2회 각 80%. 등급 확률 고급 8·희귀 47·영웅 35·전설 10. 수치는 2번 굴려 높은 쪽
- **월드보스 보상:**
  - 유니크 무기 20%(클래스별 고정 패시브)
  - 스킬북 1권 확정(5~8번 칸 새 스킬, 다시 읽으면 Lv+1, 피해 +15%, 최대 5)
  - 변신 인형 1.5%
  - 영웅·전설 장비 2회(각 85%), 골드 2,600~4,000
- **전리품:** 몬스터마다 1종. 일반 30%, 보스는 확정. 상점에서 판매

## D. 그림·소리 제작법

- **그림 = SDF 레이마칭 프리렌더(Python, numpy):**
  - 구·캡슐·상자·원뿔·토러스를 합치고 빼서 모양을 만들고, 재질은 5단계 색 램프로 칠한다.
  - 외곽선·앰비언트 오클루전·그림자를 넣고 쿼터뷰 30°로 렌더링한다.
  - 사람형은 `humanoid.Rig`(관절 각도 포즈)로 만든다. 동작은 대기 6·걷기 8·공격 8·피격 3·사망 6프레임 × 8방향이다.
  - 주의: Rig는 torso에 scale을 두 번 곱한다. 크게 키울 때는 `torso = 원하는길이 / scale²` 로 보정한다.
- **새 그림 추가:**
  - `worlds.py`에 `@F.prop(...)` 또는 몬스터 정의를 넣는다.
  - 그다음 `python3 tools/lineage/add_assets.py --monsters 이름 --props 이름` 을 실행한다.
- **큰 보스:**
  - 1.5배 해상도로 렌더링하고 게임에서 확대한다.
  - 시트 가로를 8,000px 아래로 유지해야 휴대폰 메모리가 버틴다.
  - 해당 맵에 들어갈 때만 불러온다.
- **소리:**
  - `lineage-assets/audio/sfx.js`는 합성 엔진이다. 무기 휘두름·타격·마법·몬스터 목소리를 포먼트로 합성하고, 변형 A/B/C를 고를 수 있다.
  - BGM은 장면별로 교차 페이드한다.

| 증상 | 진짜 원인 | 교훈 |
|---|---|---|
| 상점 버튼이 안 눌림 | `.hud{pointer-events:none}`이 버튼 자신에게 걸림 | 버튼 클릭을 실제 마우스·터치로 테스트 |
| 휴대폰에서 설정 아래가 안 보임 | 전역 touch-action:none, vh가 주소창 포함, iframe 안 스크롤 | 창은 탭으로 나눠 스크롤 없이 한 화면에 |
| 조이스틱이 가끔 안 먹힘 | 로그 글자(HUD)가 터치를 가로챔 | 글자 HUD는 pointer-events:none |
| 휴대폰 화면이 작게 보임 | viewport 메타 없음 | 첫 줄에 viewport 메타 |
| 오크 소리가 끝없이 겹침(초당 200회) | 마을 경계에서 추격↔대기가 매 프레임 바뀌며 함성 | 상태 전환 대기 + 소리 횟수 제한 |
| 캐릭터가 나무·횃불 사이에 끼임 | 출현 자리·되돌림 위치가 막힌 칸 | 도달 가능 영역 + safeSpot + 자가 탈출 |
| 자동사냥 제자리걸음 | 갈 수 없는 몬스터를 계속 선택 | 막히면 그 대상을 잠시 건너뜀 |
| 경험치를 올렸더니 오히려 너무 빨라짐 | 리젠보다 경험치 배율 효과가 큼 | 시뮬레이션으로 측정 후 결정 |
| 탭 추가 후 조이스틱이 설정창 안에 들어감 | 닫는 태그 하나 누락 | 큰 HTML 수정 후 DOM 부모 검사 테스트 |
