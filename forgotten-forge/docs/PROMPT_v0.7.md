# 잊혀진 대장간 v0.7 업데이트 — 프롬프트 버전

원래 요청서를 **그대로 구현할 수 있게** 수치·규칙·완료 기준을 채운 버전입니다. `---` 사이를 복사해 쓰면 됩니다.

---

## 역할과 전제
너는 HTML5 캔버스 쿼터뷰 RPG 「잊혀진 대장간」 개발자다. 본체는 `forgotten-forge/tools/lineage/game_template.html`이며, `gallery.py`로 `forgotten-forge/index.html`을 만든다. 새 그림은 `tools/lineage/worlds.py`(SDF 프리렌더)에 추가하고 `add_assets.py`로 렌더링한다. 모든 문구는 한국어, PC·휴대폰을 모두 지원한다.

## 1. 게임플레이·밸런스
1. **리젠 하향:** 일반 몬스터 리젠 25초 → **60초**. 보스·월드보스는 그대로.
2. **비례 보상·난이도:** 일반 몬스터 체력 ×1.3, 공격력 ×1.2, 경험치 ×1.4. 밸런스 시뮬레이션(`tests/balance_sim.js`)으로 35분 성장 속도가 이전 버전과 비슷한지 확인한다. 경험치를 너무 올리면 리젠이 느려도 성장이 오히려 빨라지므로 측정해서 정한다.
3. **선공/후공 50:50:** 몬스터 출현 자리를 만들 때 순서대로 번갈아 배정한다(맵마다 정확히 절반). 선공은 접근 반경 안에 들어오면 먼저 공격하고, 후공은 맞기 전까지 공격하지 않는다(맞으면 4칸 안의 같은 종류 후공 몬스터도 함께 반격). 선공 경험치 +15%. 보스·월드보스는 선공.
   - **표시:** 머리 위 빨간 ▼(선공, 추격 중이면 더 진하게) / 초록 ●(후공), 대상 정보창에 `▼선공`/`●후공`, 미니맵 점 색(빨강/노랑), 시작 화면 안내.
4. **오크 전사 소리 버그:** 원인 = 플레이어가 마을 경계에 있거나 추적 한계를 벗어날 때 몬스터가 매 프레임 '추격↔대기'를 오가며 그때마다 50% 확률로 함성을 냄(측정: 초당 약 200회 겹침). 고블린도 같은 오크 목소리를 쓴다. 수정:
   - 추격을 그만두면 4초간 다시 선공하지 않음, 마을 안의 플레이어에게는 선공하지 않음
   - 몬스터마다 목소리 대기 2.5초, 같은 소리는 0.09초 안에 반복하지 않음, 몬스터 목소리는 전체 1초에 3번까지
5. **특수 옵션(패시브) 아이템 광채:** 가방 칸·장착 칸·상세 아이콘·비교창 카드에 보라↔금빛으로 숨쉬듯 빛나는 테두리 애니메이션, 땅에 떨어진 장비 둘레에 반짝이는 입자와 빛나는 테두리.

## 2. UI/UX·전투 연출
1. **피해 숫자:** 튀어나오며 커졌다 줄어드는 팝, 외곽선, 그라데이션. 입힌 피해(흰색 11px), 받은 피해(빨간색 12px, `-` 표시, 흔들림), **치명타는 21px 금빛 그라데이션 + 뒤쪽 빛살 + 'CRITICAL!' + 약간 기울어짐**, 더 오래 남음.
2. **아이콘 메뉴:** 자동·가방·뽑기·소리·설정을 **맵 창 왼쪽 위에 세로 아이콘**(SVG + 작은 글자)으로. 켜짐 상태는 금빛 테두리 발광, 소리 끔은 회색. 휴대폰은 글자 없이 아이콘만 36px.
3. **사운드 상세 설정:** 전체·배경음악·효과음·몬스터 소리·환경음 각각 0~100 볼륨 슬라이더 + 켜기/끄기, 저장. M 키는 전체 음소거.
4. **강화 연출(가방 안):** 모루 위 장비를 망치로 세 번 두드림(타격마다 불꽃·쇳소리, 약 1초) → **성공:** 금빛 기둥·회전하는 빛살, 장비가 떠오름, 금색 글씨 / **실패:** 장비가 회색으로 변하며 금이 가고 회색 연기, 붉은 화면, 흔들림, 빨간 글씨. 결과 소리·알림은 연출이 끝날 때. 가방을 닫은 상태에서 강화하면 연출 없이 바로 결과.
5. **비교창:** 가방에서 장비를 고르면(설정에서 끌 수 있음) 또는 `비교` 버튼, 필드에서 떨어진 장비를 누르면 5초간 → `선택한 아이템 | 같은 부위 착용 중` 카드 두 장(등급·상위 %·능력치·패시브) + 능력치별 ▲▼ 차이 + 종합 전투력 변화 + 착용 레벨 경고. 가방 안에서는 상세 정보 위 오른쪽에 붙고, 아래 버튼 클릭을 막지 않는다.

## 3. 콘텐츠
1. **웨이포인트:** 룬 비석(떠서 도는 수정, 푸른 빛 고리, 4프레임)을 필드 7곳(마을 광장·동쪽 숲·북동 묘지·오크 야영지·남서 늪지·피의 제단·지하 묘소 입구), 던전 3곳에 둔다. 2칸 안에 들어가면 활성화(배너·소리, 저장). 비석 근처 `웨이포인트 (F)` 버튼·F 키·비석 탭 → 활성화된 곳끼리 무료 이동(던전은 Lv 5부터). 마을 광장은 처음부터 활성.
2. **이동 포탈 스크롤:** 어디서든 웨이포인트 목록을 열어 원하는 곳으로 이동, 이동할 때 1장 소모. 기존 **귀환 주문서**(즉시 마을)와 함께 상점 판매(150/60골드), 몬스터 드롭(1.5%/3%).
3. **몬스터 고유 전리품:** 몬스터마다 1종(예: 다이어울프 송곳니, 거대 거미 독샘, 오크 전사의 엄니, 몰락한 왕의 왕관 조각, 월드보스 전용). 일반 30%, 보스·월드보스 확정. 가방 `전리품` 필터, 상점 `전리품 모두 판매`.
4. **골드 뽑기(펫 / 변신 인형):** 1회 10,000골드, 11회 100,000골드(11회는 희귀 이상 1회 확정).
   - 확률·색: 일반(흰색) 70% · 고급(초록) 20% · 희귀(파랑) 8% · 영웅(보라) 1.8% · 전설(빨강) 0.19% · 신화(주황) 0.01%
   - 종류(각 10종, 등급별): 기존 몬스터·보스·월드보스 그림을 쓴다. 펫은 작게 줄여 주인공을 따라다니고(공격력·HP·골드 획득 +%), 변신은 그 모습이 된다(공격력·HP·이동 속도 +%). 등급이 높을수록 보너스가 크다(일반 2~5% ~ 신화 15~40%).
   - **천장:** 80회 안에 영웅 이상 확정(영웅 이상이 나오면 다시 셈). **마일리지:** 뽑기 1회당 1, 300이 되면 그 종류의 전설과 교환.
   - **중복:** 별(★1~5)로 강화(별 하나당 보너스 +20%), 별 5개 이후 중복은 등급별 마일리지(1~80)로 바꿈.
   - 연출: 카드 뒤집기(장마다 0.11초 간격), 등급 색 테두리, 영웅 이상은 빛나는 카드, 전설 이상은 화면 섬광과 배너. 도감 화면(보유·미보유, 별, 사용 중) + 선택 시 보너스 설명과 `데려가기/변신` 버튼. 월드보스 변신 인형을 쓰면 변신 도감에 등록된다.
5. **개발자 모드(설정 또는 F2):** 장비 드롭 100%·높은 등급 위주, 소모품·전리품 드롭 ×3, 특수 패시브 30%, 강화 100%, 뽑기 확률 20/20/20/20/15/5%, 월드보스 유니크 100%·인형 50%. 버튼: 골드 +100만, 레벨 +1, 월드보스 즉시 출현, 웨이포인트 모두 열기, 무적, 물약·주문서 99개. 켜져 있으면 화면에 `DEV` 표시.

`node forgotten-forge/tests/v07_check.js`가 모두 통과(리젠 실측 60초, 선공/후공 50:50과 행동 차이, 오크 목소리 초당 3회 이하, 광채, 비교창, 강화 성공·실패 연출, 아이콘 위치, 사운드 설정, 웨이포인트·스크롤, 전리품, 뽑기 비용·확률(40만 회 측정)·천장·마일리지·펫·변신, 개발자 모드, 휴대폰 화면 안). 기존 `update_check.js`·`iso_smoke.js`·`perf_mobile.js`·`audio_check.js`도 통과, 콘솔 오류 0건.
