# 꼬마 굴착기 놀이터

5살 아이가 혼자서도 30초 안에 조작법을 익혀 계속 가지고 놀 수 있는
브라우저 기반 굴착기 놀이 게임입니다. 자세한 기획 내용은 `DESIGN.md`를 참고하세요.

## 실행 방법

빌드나 설치 과정이 필요 없는 순수 HTML/CSS/JS입니다.

```bash
cd excavator-game
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

또는 `index.html` 파일을 브라우저에서 바로 열어도 됩니다.

## 조작 방법

- 화면 왼쪽 아래 **◀ / ▶** 버튼: 굴착기 좌우 이동
- 화면 오른쪽 아래 **⚡** 버튼: 가까이 있는 것과 자동으로 상호작용
  (바위는 부수고, 자동차는 밀고, 흙더미는 판다)
- 키보드: ← → 이동, Space / ↑ / Enter로 액션 (PC 테스트용)

목숨이나 제한 시간이 없어 실패해도 게임이 끝나지 않으며, 모든 오브젝트를
치우면 축하 연출 후 새 라운드가 자동으로 시작됩니다.

## 파일 구조

```
excavator-game/
  index.html   화면 레이아웃 (캔버스 + 버튼 UI)
  style.css    큰 버튼/반응형 스타일
  game.js      게임 로직 전체 (입력, 오브젝트, 파티클, 사운드, 렌더링)
```
