# 꼬마 굴착기 놀이터 — 기획서

## 1. 목표

5살 아이가 **어른 설명 없이 30초 안에** 조작법을 스스로 익혀 계속 놀 수 있는 게임.
"실패"라는 개념을 최대한 없애고, 뭘 누르든 재미있는 반응이 나오게 만든다.

| 항목 | 내용 |
|---|---|
| 대상 | 5세 미취학 아동 |
| 플랫폼 | 웹 브라우저 (태블릿/PC, 터치·마우스·키보드 모두 지원) |
| 주인공 | 굴착기(포크레인) |
| 실행 방법 | `excavator-game/index.html`을 브라우저로 열면 바로 실행 |

## 2. 핵심 컨셉

굴착기를 좌우로 움직여 장애물 앞에 다가간 뒤, 버튼 하나만 누르면 그 자리에 있는 것과
자동으로 "알맞은" 상호작용을 한다 (바위는 부수고, 자동차는 밀고, 흙더미는 판다).
아이는 "이동 2개 + 버튼 1개"만 기억하면 되고, 나머지 판단(무엇을 할지)은 게임이 대신 한다.

## 3. 게임 루프

```
[화면에 바위/자동차/흙더미가 몇 개 무작위 등장]
        ↓
[◀ ▶ 버튼으로 굴착기를 가까이 이동]
        ↓
[버튼(⚡) 하나로 상호작용 — 대상에 따라 자동으로 부수기/밀기/파기]
        ↓
[큰 이펙트 + 소리 + 별 보상]
        ↓
[화면의 모든 것을 치우면 "참 잘했어요!" 축하 연출]
        ↓
[새로운 라운드가 자동으로 다시 등장] (무한 반복, 게임오버 없음)
```

## 4. 실패 방지 설계 (Fail-safe)

- **목숨, 타이머, 점수 하락 없음.** 별은 계속 쌓이기만 한다.
- 이동 범위는 화면 안으로 자동 제한 — 밖으로 나가거나 낄 수 없음.
- 아무 대상이 없을 때 버튼을 눌러도 굴착기가 "끙차!" 하며 팔을 흔드는 귀여운 반응만 하고,
  절대 패널티가 없음 → 아이가 "막 눌러도 안전하다"는 걸 스스로 학습.
- 모든 상호작용은 여러 번 눌러도 실패하지 않고 결국 성공으로 끝남(강도 실패 없음, 확률 없음).

## 5. 조작 방법 (전부 이 3개가 전부)

| 버튼 | 위치 | 동작 |
|---|---|---|
| ◀ (왼쪽 이동) | 화면 왼쪽 아래, 큰 원형 | 굴착기가 왼쪽으로 이동 |
| ▶ (오른쪽 이동) | ◀ 버튼 바로 옆 | 굴착기가 오른쪽으로 이동 |
| ⚡ (액션) | 화면 오른쪽 아래, 크고 색이 다름 | 가까운 대상과 자동 상호작용(부수기/밀기/파기) |

키보드도 동일하게 지원(← → 이동, Space/↑ 액션) — PC 테스트 및 취향에 따라 사용.

## 6. 화면 구성 (UI)

- **상단 중앙**: 별 개수만 보여주는 작은 카운터 (⭐ 12) — 숫자를 못 읽어도 별이 쌓이는 것만으로 성취감.
- **화면 대부분(필드)**: 밝은 하늘 + 초록 잔디 + 갈색 흙길, 그 위에 바위/자동차/흙더미가 배치.
- **화면 하단**: 좌측에 이동 버튼 2개, 우측에 액션 버튼 1개. 모두 손가락 굵기 이상의 큰 원.
- **글자 최소화**: 버튼은 글자 대신 화살표/번개 아이콘 사용 (아직 한글을 못 읽는 아이 배려).
- **색상**: 원색 위주(하늘색·초록·주황·노랑)로 대비를 크게 주어 직관적으로 인식.

## 7. 오브젝트별 상호작용

| 오브젝트 | 반응 | 보상 |
|---|---|---|
| 바위/상자 (장애물) | ⚡ 한 번에 "펑!" 부서짐 — 파편 튀고 화면이 살짝 흔들림 | 별 +1, "쨍그랑" 효과음 |
| 자동차 | ⚡ 누를 때마다 조금씩 밀려나다가 화면 끝에서 "빵빵!" 하며 퇴장 | 별 +1, 클랙슨 효과음 |
| 흙더미 | ⚡ 누를 때마다 흙이 파여 작아지다가 마지막에 반짝이는 보석이 나오며 사라짐 | 별 +1, "삽질" 효과음 + 반짝임 |

모든 상호작용은 실패가 없고, 누적 입력에 관계없이 결국 완료된다(입력을 더 하면 더 빨리 끝날 뿐).

## 8. 사운드/이펙트 (보상 연출)

- 효과음은 외부 음원 파일 없이 Web Audio API로 즉석 합성 (오프라인에서도 항상 재생 보장).
- 부수기: 짧은 노이즈 버스트 + 하강 피치 "쨍그랑"
- 밀기: 통통 튀는 "빵빵" 클랙슨음
- 파기: 낮은 "퍽" 삽질음
- 라운드 클리어: 상승 아르페지오 + 화면 가득 색종이(컨페티) + "참 잘했어요! 🎉" 큰 배너

## 9. 완료 기준 (Definition of Done)

- [x] 이동(◀▶) + 액션(⚡) 버튼만으로 모든 콘텐츠를 즐길 수 있다
- [x] 아무 것도 없는 곳에서 액션을 눌러도 패널티 없이 반응만 있다
- [x] 바위 부수기 / 자동차 밀기 / 흙 파기 3종 콘텐츠가 모두 동작한다
- [x] 상호작용 시 시각(파티클/흔들림) + 청각(효과음) 보상이 즉시 나온다
- [x] 모든 오브젝트를 치우면 축하 연출 후 새 라운드가 자동 생성된다(게임오버 없음)
- [x] 버튼이 화면 크기에 따라 항상 크게 유지된다(반응형)

## 10. 코드 구조

```
excavator-game/
  index.html   화면 레이아웃 (캔버스 + 3개의 큰 버튼)
  style.css    큰 버튼/반응형 스타일, 밝은 색상 테마
  game.js      게임 루프, 오브젝트 스폰, 입력 처리, 파티클, 사운드 합성
```
